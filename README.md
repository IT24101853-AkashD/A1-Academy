# A1 Academy - Online Learning & Tutoring Platform

Welcome to the A1 Academy project repository!

## Project Structure
- `/frontend`: React.js (Vite) application
- `/backend`: ASP.NET Core Web API (Configured for PostgreSQL)
- `/.github/workflows`: GitHub Actions CI pipeline

## Local Setup Instructions

### Prerequisites
- Node.js (v20+ recommended) for the frontend.
- .NET SDK (v8.0+ recommended) for the backend.
- PostgreSQL Database.

### Frontend (React)
1. Navigate to the frontend directory: `cd frontend`
2. Install dependencies: `npm install`
3. Start the development server: `npm run dev`

### Backend (ASP.NET)
1. Ensure the .NET SDK is installed on your machine.
2. Navigate to the backend directory: `cd backend`
3. Run the application: `dotnet run`
